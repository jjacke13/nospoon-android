Application and original artwork: GPL-3.0-only; source:

This application uses hyperdht-cpp and its Kotlin/JNI bindings under LGPL-3.0.
Complete GPL-3.0 and LGPL-3.0 texts are bundled with this application.
The library is statically linked into libhyperdht_jni.so; the complete public
application/native sources, build scripts and patch permit rebuilding and
relinking a modified library. No developer signing key is required for your
own development installation (Android requires your own installation signature).

https://github.com/jjacke13/nospoon-android/blob/v0.1.4/fdroid/patches/android-jni.patch

Build/relink recipe and prerequisites:
https://github.com/jjacke13/nospoon-android/blob/v0.1.4/docs/FDROID.md
1. Clone this application source with git clone --recurse-submodules.
   Git records each native revision, including HyperDHT's nested libudx module.
2. Run scripts/prepare-native-sources.sh native/hyperdht.
3. Run scripts/build-jni-from-source.sh HYPERDHT SODIUM UV NDK WORK OUTPUT_SO
   with a fresh WORK directory and OUTPUT_SO at app/src/main/jniLibs/arm64-v8a/libhyperdht_jni.so.
4. Use JDK 21 and Android SDK 36/build-tools 36.0.0, then ./gradlew assembleDebug
   (your own development signature), or assembleRelease for unsigned packaging.
The native script builds static dependencies and JNI from source without
fetching prebuilt application libraries. Use a suitable Linux build host.
